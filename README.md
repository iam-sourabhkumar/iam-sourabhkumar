## What I do

- **Infrastructure as Code:** reusable Terraform modules for networking, compute, storage, security and application services on Azure.
- **CI/CD:** Azure DevOps YAML pipelines and GitHub Actions, including composite actions and workflow templates that cut pipeline authoring effort by 40%.
- **DevSecOps:** Tfsec, TFLint and Checkov in CI for IaC security scanning, validation and compliance checks.
- **Azure governance:** Landing Zone design, HLD and LLD documentation, RBAC and Azure Policy.
- **Observability:** Azure Monitor, Log Analytics workspaces and alert rules for proactive incident detection.
- **Automation:** Bash and PowerShell scripts for self-service environment creation and teardown.
